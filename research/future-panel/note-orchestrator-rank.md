# Ранжир оркестратора до прихода судей (для сверки независимости)

## Tier 1 — сам шаг

1. **tau-record/7 «партитура путешествия»** — сошлись 13 из 15. Разрыв реален,
   пользователь прямо просил «шаринг, который воспроизводится». Ядро дизайна:
   дискретные события камеры (travel/focus с длительностями, easing — Codex-инженер),
   `systemId` на событиях выступления, гостевые рождения с полной спецификацией
   тел (Claude-инженер + внутренний инженер), `catalogRevision` (пин версии
   атласа — 4 агента), tick 120 Гц вместо float-времени (Codex-инженер),
   scoreStore обязателен для длинных записей. НЕ непрерывная камера (отвергли
   трое). Петля ответа — через существующий `createReplyComposition` + lineage.

2. **«Поющие звёзды»** — сошлись 3 из 3 астрономов. Флагман PSR B1257+12
   (честные 160,8 Гц + планеты в резонансе 3:2 — система, которую буквально
   услышали первой) и PSR J0437−4715 (173,7 Гц, множитель ровно 1).
   Цефеиды/RR Lyrae: измеренные кривые блеска = природные огибающие.
   Строб-безопасность обязательна (вспышка ≤2–3 Гц, reduced-motion).

## Tier 2 — усилители (дёшево, большой эффект)

3. **Рождение мира как событие света** (2/2 дизайнера): вспышка в цвете
   голоса + кольцо за один кеплеровский период. 2–3 дня, главный wow онбординга.
4. **Собор 2.0**: фигура всей резонансной цепочки вместо парной арки. ~неделя.
5. **Лечение однообразия каталога**: HD 80606 b (e=0,93 — природное рубато),
   WD 1856+534, K2-22b. Только данные — дешевле всего.

## Мои атаки

- Интерлюдии светового запаздывания (ноги мечтателя): музыкально опасны
  (скука), тайминги камеры тяжелы; заменить доплер-глиссандо перелёта
  (Claude-дизайнер) — тот же смысл, цена в разы ниже.
- «Пульсарный барабан» как отдельный ритм-слой: Codex-инженер прав — игла,
  луны и чужие струны уже дают ритм; пульсар идёт как ГОЛОС, не как секвенсор.
- Непрерывная запись камеры: отвергнута тремя инженерами — дискретные фокусы.

сделан) + тесты + E2E «автор → ссылка → слушатель».
